TrailWaver — Documentation

Charger une trace

Sélectionner un fichier dans la liste déroulante (dossier input/) ou cliquer sur 📂 Ouvrir GPX depuis le PC pour uploader un fichier local. Le fichier est validé côté serveur puis chargé automatiquement. Le bouton 🗑 Supprimer ce fichier GPX supprime définitivement le fichier après confirmation.

Données de relief

Les pentes et le D+/D- nécessitent des altitudes sur chaque point. Deux sources :

SourcePrécisionComment l'obtenir
GPS natif±3–10 m verticalPrésent dans le GPX si l'appareil l'a enregistré — chargé automatiquement
SRTM NASA 90 m±10–20 mBouton 🏔 Charger topo SRTM (toolbar ou bannière sidebar). Téléchargé et mis en cache localement. Un lissage gaussien (fenêtre 5 pts) élimine les artefacts de grille.

Si aucune altitude n'est détectée au chargement, la bannière orange apparaît dans la sidebar avec le bouton SRTM et un champ de saisie manuelle D+/D- (pour la mesure uniquement).

Types de route OSM

Le bouton 🛣️ Types route (toolbar ou bannière sidebar) interroge l'API Overpass pour récupérer les types de voie (highway, surface, tracktype) dans l'emprise de la trace. Une fois chargés, ils colorent la trace en mode Type route et ajustent le score de difficulté (pondération 70 % pente / 30 % type).

Score de difficulté

Calculé par tronçon de N mètres (réglable dans la barre d'analyse, défaut 500 m) :

ScoreLabelPente p90
★ Facile1< 3 %
★★ Aisé23–7 %
★★★ Moyen37–13 %
★★★★ Difficile413–22 %
★★★★★ Extrême5≥ 22 %

Bonus sinuosité (quand OSM absent) : les points sont rééchantillonnés à 25 m, puis les angles de cap sont mesurés. Les virages (15°–45°) comptent 0,5 pt, les épingles (>150°) comptent 2 pts. La densité pondérée en virages/km ajoute 0 à +1,5 au score final.

Avec OSM chargé : le bonus sinuosité est remplacé par la combinaison 70 % pente / 30 % type de route.

Outil Mesurer

Cliquer 📏 Mesurer puis poser le point A sur un point de la trace, puis le point B sur la même trace. Les stats (distance, D+, D-, pente moy., pente max., sinuosité, difficulté) s'affichent dans le panel flottant. Si les altitudes sont absentes, le bouton 🏔 Charger topo SRTM est proposé directement dans le panel, ainsi qu'un champ D+/D- manuel. A et B doivent appartenir à la même trace.

Recherche de lieu

Champ 🔍 Lieu, col, site… dans la toolbar. Utilise l'API Nominatim (OpenStreetMap). La recherche est biaisée sur le viewport courant mais non bornée. Cliquer un résultat centre la carte et pose un marker rouge temporaire (12 s).

Mode dessin

Bouton ✏ Dessiner (ou touche D). Chaque clic ajoute un point ; double-clic valide ; clic droit annule le dernier point ; Échap annule tout. Si les types route OSM sont chargés, le curseur snape automatiquement sur le segment le plus proche (rayon 30 px, surligné en cyan). La trace créée est ajoutée comme track normal (sans altitude — lancer SRTM après si besoin).

Sélection rectangle

Bouton ▭ Rectangle (ou touche R). Dessiner un rectangle sur la carte pour sélectionner tous les points à l'intérieur. Les boutons Désél. / Inverser / 🗑 Suppr. / ↩ opèrent sur la sélection.

Vue 3D

Bouton 🏔️ 3D — bascule vers MapLibre GL avec terrain DEM (AWS Terrarium). Le curseur Exag. règle l'exagération verticale (×1 à ×5). Nécessite les altitudes SRTM ou GPS pour une représentation correcte.

Export GPX

Bouton ⬇ Export (activé après chargement). Exporte en GPX standard ou GPX coloré Garmin/OsmAnd selon le mode de couleur actif. Les annotations et commentaires de tronçon sont inclus dans la version annotée.
